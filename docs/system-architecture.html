风控模块（横切层）
  • RiskService：埋点 + 拦截门面，覆盖控制层 / 业务层 / 数据层
  • R0 封禁黑名单（登录 + 抢票入口均校验 · 不受总开关约束）
  • R1 单用户滑动窗口限频（10s 内 5 次，命中惩罚 30s）
  • R2 同 IP 多账号检测（默认关闭，防 NAT 误杀）
  • 分级处置：30s 自动惩罚 → 限时 7/30 天 → 永久封禁
  • GrabLog 抢票日志全量埋点（成功 / 失败 / 拦截原因）
  • 命中即实时拦截并返回提示，记录 RISK_BLOCKED 日志
  • 管理端风控监控大盘（异常账号、拦截记录）
总开关可配置 · 风控异常只告警，不阻断抢票主流程
